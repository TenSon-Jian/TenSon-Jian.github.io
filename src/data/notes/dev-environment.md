记录一下我现在用的开发环境。它不是最优解，只是我用了三年还没有换掉的东西。

## 编辑器与终端

- **编辑器**：VS Code，主题用最朴素的浅色，字号 14，行高 1.7
- **终端**：Windows Terminal + PowerShell 7，配色也是暖色系，和编辑器保持一致
- **字体**：正文用 Inter，等宽用 JetBrains Mono

关于字体我有一点执念：**同一块屏幕上不要出现两种气质冲突的字体**。等宽字体带连字（ligature）我很喜欢，`=>`、`!==` 看起来更整。

## 常用命令

```bash
# 起项目
npm install --ignore-scripts
npm run dev

# 构建前先看类型
npx vue-tsc --noEmit

# 搜索时排除产物目录
rg "useGithub" -g '!dist' -g '!node_modules'
```

## 我的效率习惯

1. **先写最小的可运行版本**，跑起来再补细节
2. **提交信息写清楚"为什么"**，而不是"改了什么"
3. **每个模块只留一个出口**（`index.ts` 统一导出）
4. **不装用不上的插件**，编辑器越干净越容易专注

## 值得的投入

| 投入 | 回报 |
| --- | --- |
| 花时间整理目录结构 | 三个月后还看得懂 |
| 统一命名规范 | 搜索时命中率极高 |
| 写一点注释解释取舍 | 少一次"当时为什么这么写" |
| 保持提交粒度小 | 出问题能快速定位 |

## 一些不那么重要的

壁纸、状态栏美化、花哨的进度条动画——都试过，最后全删了。桌面越空，坐下就能开始写。

> 环境的意义是让你更快地进入状态，而不是让你更久地停留在配置里。
