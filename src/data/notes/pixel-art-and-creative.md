除了写代码，我还会画一点像素图。它和写前端有一个共同点：**在有限的格子里做取舍**。

## 为什么是像素

像素画的约束非常硬：

- 画布只有 32×32 或 64×64
- 颜色通常限制在 12～16 色
- 一条线只有整数坐标，没有抗锯齿

约束越硬，越容易做出统一的风格。这一点和设计系统很像——**调色板越少，界面越整齐**。

## 我常用的色板

做像素图时我固定用一个偏暖的 8 色板，和这个网站的颜色几乎是同一族：

| 用途 | 色值 |
| --- | --- |
| 高光 | `#F5F1E7` |
| 亮部 | `#E3DCCB` |
| 中间调 | `#C2BAA8` |
| 暗部 | `#8F887A` |
| 重暗部 | `#625C52` |
| 强调 | `#A2685C` |
| 阴影 | `#353535` |
| 线稿 | `#20201F` |

## 和网站的呼应

你可能注意到本站的一些视觉元素是"简化到不能再简化"的：

- Logo 只是一对耳朵的轮廓
- 项目截图是抽象的程序化线框
- 404 页面里的角色没有五官细节

这些都是像素思维的延续：**先减到只剩必要线条，再考虑要不要加东西**。

## 一些作品方向

1. 兽人角色的行走图（四方向 4 帧）
2. 头顶的小图标集（16×16，用于游戏 HUD）
3. 一些安静的室内场景，暖色灯光

偶尔会把进度发到社交平台上，但大多数时候它们只是躺在硬盘里。创作这件事，做出来本身就够了。
